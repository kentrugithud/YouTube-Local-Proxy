# YT-Local-Proxy

Программа для Windows, которая помогает открывать YouTube там, где он тормозит или не загружается.
Трафик YouTube идёт через ваш личный Cloudflare Worker, остальные сайты открываются как обычно.

## Возможности

- Автонастройка Windows (PAC): через программу идёт только YouTube. Если программа закрыта,
  браузер сразу открывает сайты напрямую, ничего отключать вручную не нужно.
- Включение и выключение одним кликом по иконке в трее.
- Кнопка «Тест» проверяет, что через ваш Worker открывается YouTube.
- Автообновление: программа сообщает о новой версии и умеет скачать и установить её сама.

## Как начать

1. Создайте свой Cloudflare Worker по гайду: https://kentrugit.github.io/cfw-ytlp/
2. Скачайте `YT-Local-Proxy.exe` со страницы [Releases](https://github.com/kentrugithud/YouTube-Local-Proxy/releases/) и запустите.
3. ПКМ по иконке в трее → **Настройки** → **Cloudflare Worker**: включите «Свой домен»,
   впишите домен Worker, нажмите «Тест» и «Сохранить».
4. Кликните по иконке в трее (или выберите пункт «YouTube-прокси»), затем перезапустите браузер.

Подробнее: [docs/WebProxy.md](docs/WebProxy.md).

## Важно

- Нужен свой бесплатный Cloudflare Worker. Не публикуйте его домен.
- У бесплатного Worker есть дневной лимит запросов, скорость видео в высоком качестве может быть ниже.
- Работает в браузерах, которые используют системные настройки прокси (Chrome, Edge, Firefox, Яндекс и др.).

## Сборка из исходников

Нужен Python 3.10–3.12 (64-bit).

```
install.bat   # создаёт venv и ставит библиотеки
build.bat     # собирает dist\YT-Local-Proxy.exe
```

Версия задаётся в `proxy/__init__.py` (интерфейс) и `packaging/version_info.txt` (свойства exe).

## Выпуск новой версии

1. Поднимите номер версии в обоих файлах и соберите exe.
2. На GitHub создайте Release с тегом `v<версия>` (например, `v1.4`) и приложите файл
   с именем ровно `YT-Local-Proxy.exe`, загрузив его через сайт GitHub.
3. Программы старых версий сообщат об обновлении при следующем запуске.
