# YT-Local-Proxy

Локальный HTTP-прокси для обхода блокировки YouTube. Трафик YouTube идёт через ваш
Cloudflare Worker, остальные сайты открываются напрямую.

## Настройка

1. Создайте Cloudflare Worker: https://kentrugit.github.io/cfw-ytlp/
2. Запустите YT-Local-Proxy. ПКМ по иконке в трее → **Настройки...** → **Cloudflare Worker**:
   включите «Свой домен», впишите домен Worker (например, `name.account.workers.dev`),
   нажмите **Тест**, затем **Сохранить**.
3. Нажмите **«YouTube-прокси (автонастройка Windows)»** в меню трея (или кликните по иконке).
   В Windows пропишется «сценарий настройки» `http://127.0.0.1:8080/proxy.pac`.
4. Перезапустите браузер и откройте YouTube.

Чтобы выключить — нажмите тот же пункт ещё раз. При выходе из программы прежние
настройки Windows возвращаются сами.

Почему так безопаснее обычного прокси: сценарий отправляет через программу только YouTube,
а если программа закрыта или упала, браузер сразу открывает сайты напрямую.
Ничего отключать вручную не нужно.

## Ручная настройка вместо автонастройки (необязательно)

Параметры → Сеть и Интернет → Прокси-сервер → «Использовать прокси-сервер»:
адрес `127.0.0.1`, порт `8080`. В этом режиме через программу пойдёт весь трафик,
а при закрытой программе интернет перестанет работать, поэтому рекомендуется автонастройка.

## Консольный запуск

```
python -m proxy.yt_proxy --worker-domain name.account.workers.dev --port 8080
```

Свои домены для проксирования: `--web-domain example.com` (можно несколько раз).
По умолчанию: youtube.com, youtu.be, youtube-nocookie.com, youtubei.googleapis.com,
ytimg.com, ggpht.com, googlevideo.com.

## Ограничения

- Работает для HTTP/HTTPS; QUIC (UDP) через HTTP-прокси не идёт, браузер переключится на TCP.
- Бесплатный Worker имеет дневной лимит запросов и ограничение по скорости.
- Приложения, игнорирующие системный прокси, не затрагиваются.
